# Contributing to Flocord

Thank you for your interest in contributing to Flocord!

Flocord is a community-driven Discord client modification based on the work of previous open-source projects. Contributions of all kinds are welcome, including code improvements, plugins, documentation, translations, and bug reports.

## Contributing Code

Before contributing, make sure your changes follow the project's coding style and conventions.

Please ensure that:

* Your code is clean and readable.
* Your changes do not introduce unnecessary complexity.
* New features include appropriate documentation.
* Plugins follow the existing plugin structure.

## Reporting Issues

Before opening an issue:

* Make sure you are using the latest version of Flocord.
* Search existing issues to avoid duplicates.
* Provide detailed information about the problem.

Include:

* Your operating system.
* Your Discord version.
* Steps to reproduce the issue.
* Relevant logs or screenshots.

## Development

To work on Flocord locally:

1. Clone the repository:

```bash
git clone https://github.com/Code-Flocord/Flocord.git
```

2. Install dependencies:

```bash
pnpm install
```

3. Start development:

```bash
pnpm dev
```

## Community

Please be respectful and follow the Code of Conduct.

Thank you for helping improve Flocord!
